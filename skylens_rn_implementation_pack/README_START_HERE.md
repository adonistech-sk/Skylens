# SkyLens React Native implementation pack

This folder is intended to be placed in the EXISTING SwiftUI repository, not used to replace the app by copying screenshots.

## Contents
- `MASTER_CLAUDE_CODE_PROMPT.md`: complete prompt to paste into Claude Code.
- `reference_full/skylens_final_visual_target.png`: final chosen full 10-screen visual concept.
- `reference_screens/01_onboarding.png` ... `10_pro_paywall.png`: individual screen references cropped from the concept for review.

## One-time setup
1. Back up your existing SwiftUI project / commit your current work.
2. Copy this entire folder into the SwiftUI project as `design/visual-targets/` or tell Claude Code its actual local path.
3. In Claude Code, paste `MASTER_CLAUDE_CODE_PROMPT.md`, changing the reference path only if necessary.
4. Let Claude audit the current SwiftUI project before it writes a new app. Do not delete the SwiftUI project.
5. Check real screenshots at each development gate, not only text status messages.

## Disclaimer
This is AI-generated visual concept art for internal product design, not a finished iOS interface. Cropped reference phone mockups are artificially proportioned. Spelling, star patterns and event values may be incorrect and must not be treated as scientific data. The image must not be pasted into the production app in place of interactive UI or a scientific sky renderer.
